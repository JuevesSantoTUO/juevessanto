# 🎭 Jueves Santo - Tuna Universitaria de Oviedo

Aplicación Web Progresiva (PWA) diseñada para la gestión, comunicación y consulta de información durante la festividad del Jueves Santo y la Madrugá de Oviedo. Una herramienta moderna que combina la tradición de la Tuna con una robusta base de datos en tiempo real.

## 🚀 Características principales
- **Cancionero Digital:** Acceso rápido a las letras y repertorio de la Tuna.
- **Itinerarios y Horarios:** Rutas detalladas, eventos y fechas clave configurables.
- **Blog y Actualidad (v2.1):** Sección de noticias con maquetación avanzada (Editor Clásico y RumbiEditor por bloques), categorías, etiquetas, artículos privados y contenido restringido para usuarios registrados.
- **Censo e Inscripciones (Supabase):** Gestión integral de asistencia a la Comida, la Ronda y la Procesión de la Madrugá, con validación de solicitudes históricas mediante acordeones persistentes y filtros mixtos.
- **Panel de Control Estilo WordPress:** Interfaz de administración segmentada por roles (*Admin, Gestor, Editor*), moderación de comentarios reportados, control de usuarios y envíos de Newsletter.
- **Acceso Directo a Comunidad:** Enlace rápido para que los usuarios registrados se unan al grupo de WhatsApp de la hermandad con un solo clic.
- **PWA Ready:** Instalable en dispositivos móviles con soporte offline básico y navegación táctil optimizada.

## 📱 Instalación
Para instalar la App en tu smartphone:
1. Abre el enlace en Chrome (Android) o Safari (iOS).
2. Selecciona **"Añadir a la pantalla de inicio"** o **"Instalar aplicación"**.
3. El icono de la Tuna aparecerá en tu menú de aplicaciones.

## 🛠️ Tecnologías utilizadas
- HTML5 / CSS3 (Diseño institucional "Negro y Oro")
- JavaScript Vanilla (Estructura modular por scripts)
- **Supabase** (Base de datos online, Autenticación y Funciones RPC)
- **QuillJS** & **RumbiEditor** (Editores de contenido enriquecido)
- **SheetJS (XLSX)** para exportación de censos a Excel y CSV
- Service Workers para capacidades PWA
